# diary-config 接口文档

## 模块说明

- 模块名称：diary-config
- 模块类型：配置中心/配置聚合模块
- 主要职责：集中维护项目运行配置、服务发现配置、网关路由或公共配置文件。

## 对外接口

当前模块没有对业务前端暴露 REST Controller，因此没有独立业务 HTTP 接口。

## 使用约定

| 项目 | 说明 |
|---|---|
| 配置来源 | 以本模块配置文件及部署环境为准 |
| 消费方 | diary-gateway、各业务服务模块 |
| 变更影响 | 配置变更可能影响服务端口、路由、鉴权、OSS、MQ、数据库等运行参数 |

如后续新增配置管理 Controller，应在本文件补充接口路径、请求参数、权限要求和响应示例。
