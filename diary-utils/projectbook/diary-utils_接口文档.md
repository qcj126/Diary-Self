# diary-utils 接口文档

## 模块说明

- 模块名称：diary-utils
- 模块类型：工具类模块
- 主要职责：提供跨模块复用的工具方法、通用辅助能力和基础封装。

## 对外接口

当前模块不启动独立业务 Web 服务，也没有对外暴露 REST Controller，因此没有独立 HTTP 接口。

## 使用约定

| 项目 | 说明 |
|---|---|
| 调用方式 | 由其他 Java 模块直接依赖并调用 |
| 接口形态 | Java 方法，不是 HTTP API |
| 文档维护 | 若后续新增工具服务化接口，应补充 Controller 路径、参数和响应示例 |
